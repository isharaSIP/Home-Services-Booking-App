# Home Service Booking Application

A mobile application for booking home services such as plumbing, electrical work, cleaning, painting, and gardening.

## Technology Stack

### Frontend
- React Native
- Expo Go
- Axios

### Backend
- Node.js
- Express.js
- JWT
- Mongoose

### Database
- MongoDB Atlas

### Testing
- Postman
- Expo Go

### Version Control
- GitHub

## User Roles

- Customer
- Service Provider
- Administrator
